          先记住三条

          飞行脚本只能在笔记本上新开的「普通」SSH 窗口里运行。 tmux / screen / VSCode 内置终端 / 后台运行都会被脚本直接拒绝 —— 这些终端在 SSH 断开后不会让脚本收到 EOF，断连自动降落就失效了。--dry-run 不受限制。
          RC 的急停开关是坏的。飞行中的人工通道只有键盘（X 停桨 / L 降落）和 QGC。
          这个网页只读。它不能起飞、不发任何控制量；配置页只写档案、只跑 dry-run。

          飞行流程和按键（按键在飞行终端里按）

          起飞→悬停 5s→手动段→ 视觉跟踪段→返航→下降→自动降落
          按键悬停手动段视觉跟踪段
          WSAD— 机头方向 前 / 后 / 左 / 右抢回手动（粘性）并移动
          RF—升 / 降抢回手动并升降
          QE—左转 / 右转抢回手动并转向
          空格—原地悬停抢回手动并悬停
          T跳过手动段，直接进跟踪结束手动段，进跟踪交还视觉（MANUAL → TRACK）
          L就地降落就地降落结束跟踪 → 返航 → 降落
          X紧急停桨（空中也会立刻停 = 掉下来），最后手段
          • 手动段：松键 0.3s 自动停；5s 没按任何键会自动结束手动段、进入跟踪段（不是降落）。
          • 跟踪段开始时没有目标、或目标比进场门远 → 停在 MANUAL。用 WASD 挪近，tag 进视野后按 T。
          • 跟踪段前 5s 拒绝率超过 20% → 自动退回 MANUAL（检测质量不够，不上闭环）。
          • MANUAL 下 90s 没按键 → 结束跟踪，返航降落。目标丢失 3s → 原地悬停，重新看到自动继续。
          • SSH 断开（普通终端才有效）→ 立即就地降落。

          出事怎么办

          情况做法
          想马上降下来按 L（就地缓降 → AUTO.LAND）
          姿态失控 / 要撞人撞物按 X：立即停桨，飞机会掉下来
          键盘没反应 / SSH 卡死QGC 切 Land，必要时 QGC Kill
          用 QGC / 遥控切走了模式脚本进入「飞手接管」：不再切模式、不停桨，只发原地悬停设定点，等你把飞机降下来上锁后自己退出。 此时只有 X 还有效；Ctrl+C 只退出脚本、不动电机。 如果又切回 OFFBOARD，飞机原地悬停，用 QGC 切 Land 降落
          空中按了 Ctrl+C / 脚本报错退出不会停桨：脚本请求 PX4 AUTO.LAND 后退出，PX4 自己降。 终端会打印是否切换成功，没成功就立刻用 QGC 切 Land
          脚本自己触发了「缓降」正常现象：VIO 老化、视觉断供、速度/围栏超限、电压低都会就地缓降（返航途中也一样）。看「监控」页横幅和事件里的原因
          脚本自己触发了「停桨」只有三种来源：倾角持续超限、MAVROS 断链、操作员按 X。复盘看日志

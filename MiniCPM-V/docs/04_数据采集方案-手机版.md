# 手机拍摄方案（2026-11-05 起 3 天，替代无人机采集）

> 用途：为 MiniCPM-V 离线评测补充样本（岗位 A 的"D10 数据门"）
> 交付：≥200 张图 + 一张元数据表

---

## 0. 手机能不能替代无人机相机？

**基本可以，但有两个前提。**

| 项 | 无人机检测相机 | 手机主摄（典型） | 判断 |
|---|---|---|---|
| 每目分辨率 | 1920×1080 | 4000×3000 | 手机更高，够用 |
| 焦距（像素）| f≈1566 @1920 宽 | f≈2889 @4000 宽 | 折到同一宽度后接近 |
| **水平视场** | **≈63°** | 1× 主摄 ≈**69°** | **差 9%，可以后期对齐** |
| 快门 | 滚动快门 | 滚动 + HDR 合成 | 手机 HDR 会"美化"，需记录 |
| 噪点/压缩 | MJPG 压缩 | HEIC/JPEG 强降噪 | 真实感不同，**报告中注明** |

**结论：** 手机 1× 主摄拍的数据，**可以用来评 VLM 的语义理解**，
但不能用来评"成像质量极限"（噪点、压缩伪影、运动模糊那类）。

**必须做的两件事：**
1. **全程用 1× 主摄**（不要超广角、不要长焦、**不要数码变焦**）
2. 每张都记 **机型 + 距离 + 条件**，我后期统一重采样到"1920 宽 / ≈63° 视场"

## 1. 拍摄规范（不遵守的话数据作废）

| # | 要求 | 原因 |
|---|---|---|
| 1 | **1× 主摄**，手指不要在镜头前 | 长焦/广角焦距不同，无法与无人机对齐 |
| 2 | **16:9**，最高分辨率，全程统一 | 无人机是 16:9；混用画幅会让裁剪比例乱掉 |
| 3 | **不要数码变焦、不要裁图、不要加滤镜** | 变焦=插值放大，等于伪造分辨率 |
| 4 | 点屏幕**对焦在窗户上**再按快门 | 失焦的照片只能当负例 |
| 5 | 每张拍完**立刻记一行**到备忘录 | 事后回忆距离几乎一定记错 |
| 6 | 同一目标**连拍 3 张**（略偏上/偏下/偏左） | 模拟不同视角，也防手抖糊片 |

**元数据每行格式（直接抄）：**
```
文件名, 距离m, 日期时间, 天气, 光照, 楼栋, 窗位置, 开/关, 备注
IMG_2031, 30, 11-05 15:20, 晴, 顺光, 图书馆北, 3楼东2, 关, 无遮挡
```

## 2. 第一天：距离梯度（最重要，优先拍）

**找一栋能从 5 m 走到 100 m 的楼**（校园主楼、宿舍、教学楼都行）。

### 怎么拍

1. 先在近处选定**一扇特征明显的窗**（有空调外机/花盆/半开的最好记）
2. 对着这扇窗拍一张 → **后退约 10 米** → 再拍 → 再退 …… 一直到 100 m
3. 每个距离点拍 **3 张**（站的位置左右各挪半步）
4. 每拍一张记一次距离

### 距离点（能拍到多少算多少）

| 距离 | 张数 | 说明 |
|---|---|---|
| 5 m | 3 | 近距基准 |
| 10 m | 3 | |
| 20 m | 3 | |
| 30 m | 3 | |
| 50 m | 3 | |
| 80 m | 3 | |
| 100 m | 3 | **这一档最关键**（文档要求）|
| 150 m+ | 3 | 有余力再加 |

**测距办法**：手机地图量两点直线距离 / 步数 × 0.7 m / 数楼层高度（一层约 3 m）。
**记下来就行，不用非常准，±10% 可接受。**

> 这一天大约 **24 张**。看起来少，但这 24 张能画出"距离 → 识别率"曲线，
> 是整个报告里最有说服力的一张图。

## 5. 关于"用 AI 生成特殊场景"

**可以做，但要分区，不能混进主表。**

| 能做 | 不能做 |
|---|---|
| ✅ 补"开/关窗"这类**语义**样本 | ❌ 替代真实成像（没有真实噪声/压缩/畸变）|
| ✅ 造"多建筑""遮挡"的**构图**多样性 | ❌ 用来评估"远距离还能不能看清"|
| ✅ 扩充负例类别 | ❌ 拿它对外宣称"实测识别率"|

**做法：** 生成的图单独放 `data/synth/`，标注表里 `scenario` 写上 `synthetic_xxx`，
报告里**单独一栏统计**，绝不与实拍合并成一个数字。

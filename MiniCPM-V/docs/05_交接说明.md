## 0. 一句话定位

**这是"视觉模型离线评测"的工程，不是飞控工程。**
它回答：MiniCPM-V 在我们场景下能不能用、多准、多快、失败在哪。
它**不产生任何飞行指令**（项目文档 §1.2 明确排除）。

## 4. 复现一次完整评测（5 步）

```powershell
cd D:\Desktop\无人系统\MiniCPM-V
$py = "C:\miniforge3\envs\mcpv\python.exe"

# 1) 确认模型在跑
ollama list                     # 应看到 openbmb/minicpm-v4.7:1b
# 若没有：ollama serve

# 2) 生成样本（已有则跳过）
& $py eval\make_labels.py       # 自有图 → eval/crops + labels.csv
& $py eval\build_cmp_clean.py --n 200    # CMP → 客观真值 200 条

# 3) 跑评测
& $py eval\run_eval.py --mode open                       # 自有数据
& $py eval\run_eval.py --mode open --labels eval\labels_clean.csv   # 客观真值

# 4) 出报告
& $py eval\make_report.py --stamp <时间戳_open>

# 5) 出图（可选）
& $py eval\make_figures.py
```

## 5. 数据资产（别人接手最想知道"有什么"）

| 位置 | 内容 | 用途 |
|---|---|---|
| `eval/labels.csv` + `crops/` | 38 条人工标注（13 正 / 25 负）| 主评测 |
| `eval/labels_clean.csv` + `crops_clean/` | **200 条客观真值**（CMP 像素标注算出）| 最可信的一组 |
| `eval/labels_cmp.csv` + `crops_cmp/` | 45 条 CMP 跨域 | 泛化性 |
| `eval/labels_shot.csv` + `crops_shot/` | 28 条手机实拍 | 真实场景 |
| `data/external/cmp/base/` | 606 组图 + 掩膜（调色板索引，3=窗）| 可再生成任意规模样本 |
| `eval/results/` | 全部原始 json/csv | 可复算 |

**CMP 掩膜用法**：`PIL.Image.open(x.png)` 取调色板索引，`3` 是窗户。
用 OpenCV 读会展开成 RGB，读不出类别号 —— 这是个坑。

## 7. 已知坑（照做可避免重复踩）

| # | 坑 | 现象 | 处理 |
|---|---|---|---|
| 1 | **Ollama 请求缓存** | 同一张图重复问 → 0.08 s | 测时延必须每张换图 |
| 2 | **内存统计** | 只算 ollama.exe 得 85 MB | 要合计 `llama-server`（6.3 GB）|
| 3 | **主机休眠** | 单次调用 36 分钟 | 单次 >60 s 判为休眠，剔除 |
| 4 | **CMP 掩膜读法** | OpenCV 读成 RGB | 用 PIL 取调色板索引 |
| 5 | **中文路径** | `cv2.imread` 返回 None | 用 `mcpv.cv.imread_unicode` |
| 6 | **pip 装 torch** | 官方源卡住 | 用清华源 + `HF_ENDPOINT=hf-mirror.com` |
